# LetterRaid — backend

NestJS 11 + Socket.io. Forked from the Cahoots backend on 2026-08-15, carrying Heist and the
shared room infrastructure and leaving Chain / Sync / Signal / Hunch behind.

Project-level docs are mirrored into `docs/` — start with `docs/OVERVIEW.md`, and see
`docs/RULES.md` and `docs/SOCKET_EVENTS.md` before changing gameplay or the protocol. The same
files are mirrored in the frontend repo (`letterraid`); keep the two copies in sync by hand.

## Layout

```
src/
  rooms/       # room registry, codes, base gateway — shared by every game
  moderation/  # profanity filter, @Global
  health/      # GET /health
  heist/       # the flagship game: service, gateway, types, dictionary
```

One module per game, each owning its own socket namespace (`/heist`). The room registry is
namespace-agnostic, which is what makes `/room/CODE` share links work without naming the game and
what makes adding the next game cheap — see `games/future-docs/` for the queue.

## Commands

```bash
npm install
npm run start:dev     # watch mode on PORT (4042 by default)
npm test              # unit tests
npm run test:e2e      # socket + REST end-to-end
npm run lint
npm run build
```

## Ports

4042. The same box runs imposter on 4021/4022 and Cahoots on 4031/4032.

## Config

| Variable | Purpose |
|---|---|
| `PORT` | Nest listen port. |
| `CORS_ORIGINS` | Comma-separated allowed frontend origins. Read at runtime, so changing it needs a pm2 restart, not a rebuild. |

## Dictionary

`src/heist/heist.dictionary.ts` is generated by `scripts/build-dictionary.mjs` from Debian's
SCOWL-based `american-english`, reduced to 4–11 letter lowercase entries with profanity stripped
at generation time. The server never reads a system word list at runtime.
